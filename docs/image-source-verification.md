# 跨回合图片来源验证记录

验证日期：2026-10-17。目标补丁版本：`v0.18.2`。测试使用独立 QQ AppID 和隔离数据卷，未操作线上部署。

## 实现边界

- 已确认送达的生成图最多保留 10 分钟，当前引用图和带文字图片附件最多保留 5 分钟。仅保存在进程内存；读取和编辑不续期，重启、`/new` 和实际会话重置后失效。
- 共享 200 组上限，单次最多列出 8 个候选，图片最多 10 MiB，缓存字节总计 64 MiB（含未释放租约）。原有连续纯图片批次仍采用一次请求认领。
- 每条请求重新签发权限，绑定应用、群或私聊对端、发送者及实际会话；历史句柄不授予权限。当前附件／引用优先，缺失或失效不静默切换底图。
- 每步必需上下文覆盖旧快照；可选上下文抑制不能移除它。额度、文档保护、实时撤销、取消、未知投递不重试等现有约束继续执行。
- 来源归属仅在保留的生成结果或当前引用与 QQ 已确认发送回执严格匹配时标记 `origin: bot-generated`。使用 SDK 的 `ext_info.ref_idx` 专用引用索引及消息 ID；原始标识不进入模型上下文。匹配不授予生成结果的字节权限，引用仍使用自己的当前请求授权。
- 已知旧适配器源码通过严格、幂等补丁升级；不识别或缺失部分保护的布局拒绝启动。原版旧指引迁移，自定义、只读及符号链接文件保留。

## 离线和容器检查

核心缓存和原生工具回归覆盖固定 TTL、两次编辑、生成后看图、引用后看图再编辑、默认组、多图与无效来源、容量和占用租约、冻结排队快照、跨用户／应用／群／实际会话隔离、重置期间迟到结果、未知发送结果不重试，以及完整／分块出口句柄脱敏。

来源归属回归另外覆盖普通消息 ID 与专用引用索引不同的回执、相同 URL 的不相关引用、混合图片、跨用户／会话、过期和重置；原生请求装配检查当前引用中的来源字段，确认没有恢复历史图片权限或泄露回执标识。

最终本地镜像完整 `scripts/test-local.sh` 通过，41 项图片来源及升级定向回归通过。完整回归包含 profile 装配、模型／凭据路由、聊天与文档、媒体和生成、并发恢复、能力感知、升级幂等及镜像秘密扫描。双架构 CI 另外执行真实 v0.17.0 依赖卷迁移和原生 MCP→海豹容器集成。最终运行代码的[双架构完整 CI](https://github.com/YiuTerran/qqbot-dsh-docker/actions/runs/39039575158)与发布工作流均核对后再发布；镜像以发布工作流结果为准。

## 真实模型与 QQ 私聊

| 操作 | 已观测结果 |
| --- | --- |
| 不引用生成红色小鱼 | 实际图片 API 成功；QQ 附件消息 ACK 确认；回执可编辑 |
| 不引用描述刚生成的图 | 实际视觉工具成功；使用已保留的生成图 |
| 不引用将小鱼改成金色 | 实际编辑 API 成功；QQ ACK 确认 |
| 引用第一张原图并描述颜色 | 实际视觉工具成功；用户确认主要功能正常；发现来源归属信息不足，另补专用引用索引匹配 |
| 随后不引用改浅蓝背景 | 当前默认组为最近引用图；实际编辑及 QQ ACK 成功 |
| 最终来源归属复测 | 新图 QQ 回执 `ref_idx` 与入站引用索引严格相同；视觉工具前后两个模型步骤均得到 `origin: bot-generated`，用户确认来源和描述正常 |

实际主模型请求已核对必需图片来源上下文与当前工具；工具后的下一模型步骤也重新装配快照。辅助会话命名和视觉子请求不需要业务工具清单。

私聊验收不等同于真实 QQ 群验收；群聊并发、混合批次、权限隔离和文档保护由原生离线与容器测试覆盖。本次没有修改桥或海豹版本。

当前图片 CDN 在宿主机解析到非公网地址。仅在隔离测试容器内使用经 AliDNS 公共 DoH 核实的该域名公网地址，保留 HTTPS 证书及公网地址检查；宿主机 DNS 和部署配置未修改。此环境问题与来源缓存功能分开记录。

详细脱敏日志位于本机 `/tmp/qqbot-source-evidence/`，不随镜像或源码发布。真实消息正文、签名图片链接、QQ 原始身份、图片字节和凭据不得提交仓库。
