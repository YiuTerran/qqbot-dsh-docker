## 已完成

- amd64 镜像构建及实际组件版本校验通过；profile 不自动安装另一套 DSH 核心依赖。
- `scripts/test-local.sh` 完整离线回归通过，包括官方/第三方聊天、搜索凭据、人设、图片/文件、文档保护、互动澄清、OneBot 权限及并发、持久偏好与重置、升级幂等和镜像秘密扫描。
- 新版实际 Harness 请求边界通过普通、`addition-only`、`in-history` 三种模式，覆盖可选上下文抑制和回合中撤销工具。QQ 上下文刷新复用同一 agent 已接受的能力快照；历史投影不能重新暴露被过滤的工具。
- QQ 原生手工压缩链路通过；压缩后保留 sessionId、使用摘要，并提供当前能力快照。
- `scripts/test-runtime-upgrade.sh` 通过：17 项迁移测试，包含真实 v0.17.0 旧依赖树、9 个 SIGKILL 中断点、并发迁移、自定义文件保留及异常布局拒绝；另外验证旧引擎写出的日志由新引擎续接、实际入口升级及整卷快照回滚。
- 固定桥 `v0.3.1`、海豹骰 `v1.6.2-bridge.8` 的原生 MCP 容器集成通过 20 项检查。使用合成身份及隔离网络，不登录 QQ，不代表 QQ 投递验收。
- 真实 LLM 合成烟测通过 `.userid`、能力询问和命令用法咨询三项；使用当前第三方模型路由，无 QQ 投递和后端命令执行。此项验证能力理解，完整 Harness 请求的工具与上下文投影另由离线原生边界测试验证。

本次运行证据保存在本机 `/tmp/qqbot-next-evidence/`，详细离线回归日志为 `/tmp/qqbot-next-full.log`；它们不随镜像发布，不包含生产 QQ 消息。
