## 已完成

- amd64 镜像构建及实际组件版本校验通过；profile 不自动安装另一套 DSH 核心依赖。
- `scripts/test-local.sh` 完整离线回归通过，包括官方/第三方聊天、搜索凭据、人设、图片/文件、文档保护、互动澄清、OneBot 权限及并发、持久偏好与重置、升级幂等和镜像秘密扫描。
- 新版实际 Harness 请求边界通过普通、`addition-only`、`in-history` 三种模式，覆盖可选上下文抑制和回合中撤销工具。QQ 上下文刷新复用同一 agent 已接受的能力快照；历史投影不能重新暴露被过滤的工具。
- QQ 原生手工压缩链路通过；压缩后保留 sessionId、使用摘要，并提供当前能力快照。
- `scripts/test-runtime-upgrade.sh` 通过：17 项迁移测试，包含真实 v0.17.0 旧依赖树、9 个 SIGKILL 中断点、并发迁移、自定义文件保留及异常布局拒绝；另外验证旧引擎写出的日志由新引擎续接、实际入口升级及整卷快照回滚。
- 固定桥 `v0.3.1`、海豹骰 `v1.6.2-bridge.8` 的原生 MCP 容器集成通过 20 项检查。使用合成身份及隔离网络，不登录 QQ，不代表 QQ 投递验收。
- 真实 LLM 合成烟测通过 `.userid`、能力询问和命令用法咨询三项；使用当前第三方模型路由，无 QQ 投递和后端命令执行。此项验证能力理解，完整 Harness 请求的工具与上下文投影另由离线原生边界测试验证。

本次运行证据保存在本机 `/tmp/qqbot-next-evidence/`，详细离线回归日志为 `/tmp/qqbot-next-full.log`；它们不随镜像发布，不包含生产 QQ 消息。

## 真实模型与 QQ 私聊验收

使用更新后的独立测试 AppID、隔离测试数据卷和现有第三方模型路由，未登录生产机器人。实际登录、WebSocket 收消息及 QQ HTTP 回执均使用真实 SDK，不伪造用户请求或投递凭据。

| 场景 | 结果 |
| --- | --- |
| 无活跃会话 `/bot-status` | 返回部署能力，不创建会话、不调用模型 |
| OneBot 关闭时 `.userid`、能力询问和用法咨询 | 明确未启用；咨询只作文字解释 |
| 原版设定图发送 | 专用素材工具返回 `sent`，用户完成验收 |
| 澄清按钮与 Markdown | 发现并修复 v2 OpenID 错用 `specify_user_ids`；服务端继续校验原发送者、会话和一次性令牌。修复后真实按钮回调成功，用户确认 `天气预报.md` 文件名正确，正文标题一致，QQ 附件消息 ACK 成功 |
| 开启隔离 OneBot 后沿用原会话 | `/bot-status` 显示桥、MCP 和海豹后端就绪；直达 `.userid` 和 LLM `qqbot_onebot_command` 均使用真实后端结果，用户确认正常，无需 `/new` |
| 真实视觉 | 首次视觉模型返回空文本，后续简化问题后返回外观描述，用户确认正常 |
| 参考设定图生图（原 xAI 路由） | 返回 `timeout` / `UND_ERR_CONNECT_TIMEOUT`，向用户如实说明且未重试；未确认 QQ 图片投递成功 |
| 用户更新后的 Gemini 路由 | 真实 QQ 请求被下载域名的本机非公网 DNS 解析阻止；手动直测确认生成 API HTTP 200 并返回 `fileData.fileUri`。一次性容器使用经公共 DoH 独立核实的公网地址后，下载 HTTP 200，得到通过完整字节校验的 707,574 字节 JPEG。未关闭 TLS／公网检查，未修改宿主机 DNS；此项不代表真实 QQ 生图投递通过 |

最终观测钩子在能力过滤之后记录了 7 个真实模型步骤，逐项核对 `toolAvailable` 与最终工具列表一致。实际持久会话的运行上下文及请求头也已核对。QQ 验收限私聊；并发群聊、混合批次、授权撤销、文档保护和恢复继续由原生离线及容器集成回归覆盖，不把它们标为真实 QQ 群验收。

现场修复同时更新了默认指引的版本、中文附件命名规则及 v0.17.0 原版指引迁移识别；自定义、只读及符号链接指引继续保留。同时补齐上游新版会话 API 的消息统计适配：`/bot-status` 使用当前会话派生消息，不再因旧 `.events` 字段被移除而误报为零；原生压缩前后统计回归通过。镜像不自动改变服务或凭据路由；生图测试后按用户更新的 `.env` 切换至 Gemini，聊天及搜索路由不变。

本次脱敏验收摘要在本机 `/tmp/qqbot-v0.18.0-evidence/live-acceptance-summary.json`，真实消息详细记录不随镜像或源码发布。
